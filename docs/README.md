# docs — Tài liệu

- `spec.md`: đặc tả hệ thống, lấy từ Chương 1-3 của báo cáo. Đọc file này trước khi làm bất cứ bước nào.
- `annotation_rules.md`: quy tắc gán nhãn găng tay cho CHV trên CVAT. Hai người gán đọc trước khi làm.
- `video_labeling.md`: cách tạo task CVAT và quy tắc gán nhãn người, trạng thái PPE trên video.
- `experiments/`: mỗi lần huấn luyện hoặc đo đạc ghi một file. Số liệu Chương 4 lấy từ đây.
