## Báo cáo mỗi thử nghiệm (video3-6, 06b; cùng cách tính như `final5`)

Mỗi PPE: Accuracy = (Có đúng + Thiếu đúng)/(nhãn Có + Thiếu); Coverage = khung kết luận (Có/Thiếu) / khung nhãn Có+Thiếu;
Conditional Accuracy = đúng / đã kết luận; false missing = báo thiếu oan; false present = báo Có sai.
