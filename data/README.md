# data — Dữ liệu (không đưa lên Git)

- `raw/`: bốn bộ dữ liệu tải về, giữ nguyên bản gốc.
- `ppe4/`: bộ dữ liệu đã đổi về bốn lớp, làm sạch và chia tập; đây là dữ liệu để huấn luyện.
- `ppe6/`: thử nghiệm 6 lớp thêm kính, ủng bảo hộ (nhánh `exp/ppe6`).
- `videos/`: video kiểm thử lấy trên Internet và nhãn CVAT.
